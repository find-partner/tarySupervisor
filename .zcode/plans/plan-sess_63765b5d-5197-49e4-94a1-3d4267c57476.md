# 配置页与日志页新增"一键打开终端"按钮

## Context

tarySupervisor（Leptos CSR + Tauri 2 + core crate，纯 Rust）目前"打开外部"能力只有 opener 插件：打开浏览器（`open_external_url`）和打开 Finder 目录（`open_log_dir`），没有"在系统终端中打开目录"的实现。本次在两处 UI 增加一键打开系统终端的按钮，方便用户手工查看/编辑 `config.ini`、用 shell 查看日志：

- **配置页**（设置窗口左栏，常驻可见）：打开终端到**应用配置目录** `~/.traysupervisor`（便携模式下为 `TRAYSUPERVISOR_DATA_DIR`/exe 同级 `Data`，复用 `traysupervisor_core::config_dir()`，core/lib.rs:42）
- **日志页**（`#/log/<id>` 工具栏，"打开日志目录"旁）：打开终端到**该服务日志目录**；未配置文件日志时回退到默认目录 `config_dir()/logs`（比现有 `open_log_dir` 更健壮）
- macOS 用 Terminal.app（`open -a Terminal <dir>`）；Windows 用 `cmd /c start "" /D <dir> cmd`；Linux 按候选列表尝试（gnome-terminal/konsole/xfce4-terminal/x-terminal-emulator/xterm），找不到则报中文错误

## 改动

### 1. core：新增系统终端启动器（可单测）

新文件 `crates/core/src/terminal.rs`，在 `crates/core/src/lib.rs` 挂 `pub mod terminal;`：
- `pub fn terminal_command(dir: &Path) -> Result<(PathBuf, Vec<String>), String>` — 按平台构造 (program, args)，纯函数可测：
  - macOS: `open -a Terminal <dir>`
  - Windows: `cmd /c start "" /D <dir> cmd`
  - Linux: 候选 `gnome-terminal --working-directory=<dir>` → `konsole --workdir <dir>` → `xfce4-terminal --working-directory=<dir>` → `x-terminal-emulator`/`xterm`（后者以 `current_dir(dir)` 启动）
- `pub fn open_in_terminal(dir: &Path) -> Result<(), String>` — `create_dir_all(dir)` + 构造命令 + spawn + 检查退出状态（Linux 下逐候选尝试，NotFound 则下一个），错误统一 `format!("打开终端失败：{e}")` 风格
- 单元测试（`#[cfg(test)]`，照 matcher.rs:203 惯例）：断言本平台命令构造正确；CI 的 macOS/Windows 作业各自覆盖

### 2. src-tauri：两个新命令 + 注册

`src-tauri/src/commands.rs`（模板照抄 `open_log_dir` commands.rs:503-525，中文 doc comment 带 FR 编号）：
- `#[tauri::command] pub fn open_config_terminal() -> Result<(), String>` — `traysupervisor_core::terminal::open_in_terminal(&traysupervisor_core::config_dir())`
- `#[tauri::command] pub fn open_log_terminal(state: State<AppState>, id: String) -> Result<(), String>` — 日志路径解析逻辑同 `open_log_dir`（mgr.list() 找 `b.config.log.file`），`.ok_or` 换成 `unwrap_or_else(|| config_dir().join("logs"))` 兜底，再 `open_in_terminal`

`src-tauri/src/lib.rs`（generate_handler!，第 85-105 行）追加注册这两个命令。自定义命令无需改 capabilities/default.json。

### 3. 前端（Leptos）

- `src/pages/settings/mod.rs` 左栏底部（第 330-332 行 `+ 新建服务` 所在 div）：并排加 `打开终端` 按钮，`spawn_local` + `bridge::invoke_unit_res("open_config_terminal", None)`，错误按项目惯例忽略（`let _ =`，同 about.rs:26 / log_page.rs:102-108）
- `src/pages/log_page.rs` 工具栏（第 132 行"打开日志目录"后）：加 `打开终端` 按钮，闭包仿照 `open_dir`（clone `id_dir`，`invoke_unit_res("open_log_terminal", Some(bridge::invoke_args_id(&id)))`）
