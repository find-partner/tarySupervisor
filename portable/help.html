TraySupervisor Portable

跨平台系统托盘后台服务管理工具的便携版：免安装，全部数据保存在 Data\ 目录内，可放 U 盘随身携带。

Cross-platform tray-based supervisor for command-line services. No installation required; all data stays inside the Data\ folder, so the app can run from a USB drive.

使用 / Usage

  • 运行 TraySupervisorPortable.exe，从系统托盘图标进入菜单：启动 / 停止 / 重启服务、查看日志、终端视图与设置。
  • Run TraySupervisorPortable.exe and use the tray menu to start / stop / restart services, open logs, the terminal view and settings.

数据位置 / Data locations

  • 配置：Data\config.ini（与安装版 ~\.traysupervisor\config.ini 格式一致）
  • 服务日志：Data\logs\
  • WebView2 浏览器数据：Data\EBWebView\

系统要求 / Requirements

  • Windows 10+ x64，需系统已安装 Microsoft Edge WebView2 Runtime（Windows 11 与正常更新的 Windows 10 预装）。
  • Windows 10+ x64 with the Microsoft Edge WebView2 Runtime installed (preinstalled on Windows 11 and up-to-date Windows 10).

已知限制 / Known limitations

  • 同一台机器上便携版与安装版会互为单实例（先启动者生效）。
  • The portable and installed editions act as one single instance per machine.
  • 服务命令与路径引用宿主机文件系统，换机器后需按新环境调整配置。
  • Service commands reference the host filesystem; adjust the config when moving to another machine.
